# Alternative school bathroom door

Source: MAP1_S02 func_800DBB7C, callback15. This is the door scene that
eventually sets96, before the shotgun pickup. It is distinct from callback18
which rotates the two doors before the boss entrance.

gen_bathroom_motion.py extracts case3 directly, preserving elapsed-time
branches, signed16 angle increments, fixed-point multiplication, door clamp,
camera positions, acceleration/speed arguments and tween call order.
Event_TweenLinear advances its timer on every call; timer0 is called twice
in a camera update, so the position and look targets intentionally differ.
The module emits original PS1 Q12 targets and existing VC parameter units.

Native regression verifies that call order, exact target values, default and
nonzero camera parameters, zero-delta state preservation, source duration
and final door rotation at136/68 Q12 ticks. Generator comparison and make
-j4 pass with no warnings/errors. This is the motion prerequisite only;
the callback wrapper, XA sound, visibility, world prop, moving render range
and live flag/control integration remain to be connected. No scene has been
executed in an emulator or on hardware for this addition.

The scene wrapper is now generated by gen_bathroom_scene.py, reusing the
locker event conversion. It preserves cases0/1/2/3/default, XA command4152,
flags121/96, player visibility, flare suppression, border states, camera
cut/follow and return of control. Native30/60fps tests activate its real
table trigger, keep START pressed without skipping, verify no early96,
then activate and accept the shotgun pickup with the original item162
quantity6. Motion state survives another interaction and resets on overlay
entry. The generic moving-Y renderer reuses the tested locker transform.

gen_bathroom_props.py extracts DOOR_HID/GUN_HIDE poses and their original
room/pickup visibility. The map5 prop/HUD path currently exposes these two
objects only; other original lower-school objects remain unported. The
model source is the existing named-model IPD/global-bank loader.

Generator comparisons, make -j4 and native school regression pass without
warnings. GPU appearance, XA playback and physical movement through the
door remain unverified. The retail dynamic collision groups are not yet
implemented in coll.c; this remains a progression prerequisite and must
use original IPD group flags, never a guessed replacement volume.

Dynamic collision filtering is now connected for the original bathroom
room gate. The generated flag values retain Map and enable Objects only
while96 is clear. coll.c applies the original group tests to subcells
(upper two bits of each first word), ptr18 cylinders (bits8..11) and direct
surfaces (bits11..14), following collision.c1045/1725/1928. Filtering remains
opt-in; other rooms retain their previous behavior until their source
world flag branches are ported. No collision geometry was invented.

The native SU0001.IPD regression finds12 short ray paths released when
Objects is cleared. Starting outside the door collision radius, identical
movement remains blocked with Map|Objects (x18.8036) and crosses with Map
alone (x17.7020). Nearby floor height/material stay equal. The original
ladder collision regression and school scene/progression regressions pass,
as do generation comparisons and make -j4 with no warnings. Hardware
movement and GPU/XA behavior are still unverified.
