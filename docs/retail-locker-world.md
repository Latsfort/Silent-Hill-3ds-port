# Alternative school locker objects

The three moving door models now have a GPU transform path using the existing
moving-object buffer. `sh_locker_transform_vertices` retains the source Q12
Y rotation (unlike X/Z it is not reduced to Q10), rotates around each
generated pivot and preserves source UV/color payloads. Valve and locker
mask selection is separate, preventing one object's transform from being
applied to another range. Buffer preparation covers only currently visible
moving ranges. Activation is explicit and persists through interactions,
then resets with the overlay; no live driver activates it yet.

Native tests cover4096 angles for all three original door pivots, signed
fixed-point rounding, in-place operation and unchanged vertex attributes.
School tests cover selective moving masks for all32 door/body masks and
both key flags. The world-step timing/command integration remains required;
these tests do not establish GPU appearance or hardware correctness.

The roof prop generator now includes all eight original initialized objects:
valve, ball, three locker doors, two body models and the reserve key. The
locker-room chunk gate maps the world module's five draw bits onto those
models; the key uses the exact107/!108 gate. The school state retains locker
rotations, speed, timer, phase and cached draw mask across another interaction,
and clears them on overlay entry. Native school tests check all32 draw masks
with both key flags, room boundaries, state persistence and overlay reset.
The earlier valve/ball gate tests still pass with the expanded prop table.

This connects placements and visibility only. The30Hz world driver, changing
door transforms, command playback and the unopened/body event callbacks are
not yet connected to the live game. No rendered or hardware claim is made.

`gen_locker_world.py` adapts `map1_s03.c func_800DE828` directly, including
its zero-delta branch, table/flag decisions, original switch numbers and
fallthrough, RNG call order, signed rotation/speed widths, timer and sounds.
World-object submission becomes a draw mask, and sound/effect calls become
ordered output commands with original IDs, positions, Q8 volumes and flags.
The command capacity is generated from the source call sites; positions
come from the original world-object initialization and local sound constant.

`sh_locker_world_step` represents one original 30Hz world update, accepting
the original Q12 delta. Per-frame increments remain source frame increments;
this function must not be called at an arbitrary display rate. A frame-rate
adapter, world-object rendering and command playback are still required
before connecting it to gameplay. It does not replace movement with timers
or set103/106 independently of the actual source rotation/bounce branches.

Native regression follows the opening to phase6/flag103 in348 original
frames, then the body door to flag106 in153 frames. It checks effect/sound
counts and ordering data, no premature107, synchronized door rotations,
zero-delta state/RNG preservation and draw masks. A further10,000 seeded
rattle frames check reproducible state/commands/RNG and absence of story
flags. The original event callbacks, 30/60Hz integration and rendered scene
remain unfinished; no emulator or hardware verification is claimed.
